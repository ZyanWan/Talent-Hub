# 公共遮罩覆盖与滚动行为

状态：`[CLOSED]`

## 问题类型

公共遮罩 `.preview-backdrop` 只提供视觉覆盖和点击隔离，没有正确处理层叠上下文归属与根页面滚动锁定，导致遮罩在两种场景下失效。

## 表现

### 表现一：电话条目详情遮罩无法覆盖顶栏语言按钮

- `CallItemDetail` 在 `PhoneView` 的 `.phone-view` 节点内部渲染遮罩；`.phone-view` 使用带 `both` 填充模式的 `view-in` 透明度动画，形成独立层叠上下文。
- `.preview-backdrop` 使用 `position: fixed; inset: 0; z-index: 200`，但该层级只能在 `.phone-view` 的层叠上下文内参与排序；顶栏语言按钮位于电话视图之外，在页面根层叠上下文排序。
- 结果：语言按钮未被遮罩覆盖，仍可点击。

### 表现二：模态框打开后滚轮穿透背景页面

- 页面根元素允许纵向滚动：`html` 使用 `overflow-y: auto`，`body` 的纵向 overflow 为 `visible`。
- 设置弹窗、任务记录抽屉、结果预览、简历工作台、AI 对比、电话详情和确认框均使用 `.preview-backdrop` 作为公共遮罩，但该遮罩没有锁定根页面滚动。
- 在 1280 x 360 的视口中打开设置弹窗后，在遮罩空白处向下滚动，`window.scrollY` 从 0 变为 160，背景页面发生滚动穿透。

## 根因

公共遮罩只提供视觉覆盖和点击隔离：不控制自身的挂载层叠上下文，也不在遮罩挂载期间禁止根页面滚动。滚轮位于遮罩空白区域时，浏览器仍将滚动应用到可滚动的 `html`。

## 修复

- `CallItemDetail` 通过 React Portal 将遮罩直接挂到 `document.body`，使其参与页面根层叠上下文，保留原有 `z-index`、动画、ESC 和点击遮罩不关闭行为。
- 使用 `html:has(.preview-backdrop)` 在任意公共遮罩挂载期间将根元素 overflow 设为 `hidden`；遮罩卸载后选择器自动失效，根页面恢复原有滚动规则。
- 保留弹窗内部滚动容器、开合动画和嵌套模态框行为。

## 修复后验证

- 电话条目详情遮罩的直接父节点为 `BODY`；语言切换按钮中心坐标命中详情遮罩内部元素。
- 1280 x 360 视口打开设置弹窗后根元素 overflow 为 `hidden`，遮罩空白处滚动后 `window.scrollY` 保持 0，关闭后恢复为 `overflow-y: auto`。
- 前端完整单元测试和生产构建通过。
