# 电话整理判断回归

## Observations

- `apply_call_guard()` 把事实引用校验失败直接转换为字段 `含糊`，因此技术引用错误会覆盖模型对原话确定性的判断。
- 最小复现：转写内容清楚，但字段引用空 `ref` 或不存在的事实 ID 时，现有契约测试要求结果必须降为 `含糊`。
- system prompt 包含“HR 本人”要求，但程序只校验事实和结构，不拒绝“HR 询问”“候选人表示”“双方沟通”等旁观记录口吻。
- 软性输出只有 `text + fact_ids`，没有区分判断结论和简短行为依据；当前参考框架也没有要求说明候选人的工作价值或潜在用人风险。
- 旧提示词包含较多行为信号和示例，但完整恢复会增加输入长度并诱导模型套用示例。
- 最近任务包含 35 条模型事实，10 条正确 `ref` 因跨越转写片段之间的时间戳和说话人标签而校验失败；守卫随后删除至少 8 条主记录要点和 2 条软性判断。

## Hypotheses

### H1：语义确定性和证据引用有效性共用一个状态（ROOT HYPOTHESIS）

- Supports：守卫在事实引用无效时直接执行 `field.status = "含糊"`；现有测试锁定了该行为。
- Conflicts：无。
- Test：构造内容清楚、语义状态为 `已确认`、引用无效的字段，观察守卫结果。

### H2：角色要求没有进入输出验收契约

- Supports：提示词禁止旁观表达，`validate_call_structure()` 未检查旁观句式和会议纪要式标题。
- Conflicts：模型可能在部分请求中自行遵守提示词。
- Test：构造含“候选人表示”的完整摘要，验证当前结构校验是否放行。

### H3：软性判断缺少强制分析结构

- Supports：模型只需输出自由文本和事实编号，短句“沟通顺畅”也满足当前 schema；参考框架主要列出维度定义。
- Conflicts：能力较强的模型可能自行给出深入判断。
- Test：检查当前 schema 和结构校验是否接受没有维度、价值/风险结论和简短行为锚点的软性文本。

### H4：提示词压缩本身导致全部回归

- Supports：问题出现在提示词重构后，电话 system prompt 固定文本明显缩短。
- Conflicts：事实误判由确定的程序赋值触发；单纯增加提示词不能修复状态混用，也不能保证视角合规。
- Test：保持现有提示词不变，单独检查程序守卫和结构校验的行为。

### H5：程序插入的转写元数据切断连续原话引用

- Supports：失败引用由多句连续原话组成，渲染文本在句间插入时间戳和说话人标签。
- Conflicts：无。
- Test：校验前仅移除时间戳和说话人标签，再核对最近任务全部事实引用。

## Experiments

### E1：字段引用失败最小复现

- 输入：清楚的转写文本；字段状态 `已确认`；字段引用空引用事实或不存在的事实 ID。
- 结果：现有测试期望两个字段均变为 `含糊`。
- 结论：H1 confirmed。

### E2：角色约束静态路径检查

- 输入：沿 `模型输出 -> apply_call_guard() -> validate_call_structure() -> render_remark_narrative()` 检查所有验收条件。
- 结果：没有旁观句式或会议纪要标题校验。
- 结论：H2 confirmed。

### E3：软性结构静态检查

- 输入：检查 `CallSoftSkillObservation`、模型输出 schema 与 `validate_call_structure()`。
- 结果：只要求自由文本和事实 ID，结构校验不拒绝泛化判断。
- 结论：H3 confirmed。

### E4：最近任务全部引用复核

- 输入：最近任务的 35 条事实引用和 12,923 字转写文本。
- 结果：直接核对有 10 条失败；仅移除程序插入的时间戳和说话人标签后，35 条全部逐字核对通过。
- 结论：H5 confirmed。

## Root Cause

电话整理把语义确定性、引用可靠性、写作视角和招聘判断深度都交给同一段自由文本提示；事实守卫使用带时间戳和说话人标签的渲染文本核对跨片段原话，并错误地用 `含糊` 表示引用失败。

## Fix

- 删除业务语义守卫，程序不删除正文或招聘判断，也不改写字段状态。
- 程序只校验 JSON、必填章节和字段；事实引用仅用于录音定位。
- 提示词统一使用高级招聘专员角色，要求直接面向用人部门书写完整记录。
- 软性判断使用普通字符串，不限定维度；结论详写，行为依据简写。
- 只吸收高价值行为信号，不恢复完整示例表。
