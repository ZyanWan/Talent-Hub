# STT 文本后处理方法论：全局语境约束重建法

## 一、方法论定位

本方法论研究的对象，不是音频，也不是 STT 模型本身，而是 **STT 模型已经生成的不规则对话文本**。

推理模型接收到的材料只有文本。文本中可能存在：

- 发言人归属错误；
- 多个人的话被合并；
- 同一个人的话被切碎；
- 错字、同音词和数字误识；
- 重复、重叠和标点混乱；
- 局部语义不通或上下文断裂。

因此，后处理的本质不是重新进行语音识别，而是：

> 在不接触音频的条件下，利用全文语境、对话结构和语言规律，对 STT 文本所代表的原始对话进行约束性重建。

这里的"重建"不是创造一段更合理的对话，而是在已有文本证据范围内，恢复最可能接近真实对话的结构和表达。

## 二、核心问题

可以把真实发生的对话记为 D，把 STT 输出的不规则文本记为 O。

O 不是 D 的完整复制，而是 D 经过语音识别、说话人划分、断句和标点恢复后形成的带噪结果。推理模型无法直接获得 D，只能根据 O 推导出一个最可信的重建结果 D*。

方法论追求的不是"最流畅的文本"，而是同时满足以下条件的结果：

- 与原始文本保持最大程度的一致；
- 与全文上下文保持连贯；
- 与人物角色和对话功能保持一致；
- 对原文所做的修改尽可能少；
- 不引入原文无法支持的新信息。

可以将其概括为：

**最可信重建 = 全文语义一致性 + 对话结构一致性 + 角色行为一致性 + 语言合理性 - 无依据修改**

这决定了 STT 后处理不是普通润色，而是一种受原文约束的文本推理任务。

## 三、方法论的基本假设

### 1. 原始文本虽然有噪声，但不是完全失真

STT 输出中的局部词语、说话人标签和断句可能错误，但大多数内容仍然保留了原始对话的顺序、主题和部分语义。

因此，不能因为局部不通顺就否定整段文本，更不能随意删除。

### 2. 对话具有结构冗余

真实对话中的信息会以不同形式重复出现：

- 问题会限定回答范围；
- 回答会被对方复述或确认；
- 后续追问会反向说明前一句的含义；
- 姓名、机构和主题会在全文中多次出现；
- 人物会保持相对稳定的语言功能。

这些重复出现的关系，为纯文本推理提供了恢复依据。

### 3. STT 错误往往是局部的，对话逻辑通常是全局的

某个词可能识别错误，某个标签可能归属错误，但完整对话仍然会表现出提问、回答、解释、确认和转场等稳定关系。

因此，判断不能只依赖当前一句，而必须由全文反向约束局部。

### 4. 不确定性无法被完全消除

没有音频意味着某些低声、重叠、方言或专有名词无法被唯一恢复。

高质量后处理的目标不是消灭所有不确定性，而是区分：

- 可以高置信恢复的内容；
- 可以推断但仍有其他可能的内容；
- 仅凭文本无法确认的内容。

保留不确定性，是保真方法的一部分。

## 四、总体推理框架

全局语境约束重建法采用"全局建模、局部重建、全局回验"的循环。

### 1. 全局建模

先从全文中建立三个基础模型：

- **事实模型**：姓名、机构、地点、时间、数字、活动和主题。
- **角色模型**：谁主要提问、谁主要回答、谁解释规则、谁复述确认、谁控制主题转换。
- **对话模型**：问题如何推进，回答如何出现，话题如何切换，活动如何开始和结束。

全局建模的目的，是获得判断局部文本时所需的约束条件。

### 2. 局部重建

在全局模型约束下，对每一处异常进行分析：

- 这段话是否包含多个发言人的内容；
- 这个短片段是否是上一句话的续接；
- 这句话是在提问、回答、复述还是评价；
- 某个错词是否存在唯一的上下文恢复方式；
- 某次重复是机器抖动、真实强调还是另一人的复述。

局部重建只解决当前证据能够支持的问题，不扩大修改范围。

### 3. 全局回验

局部调整后重新阅读全文，检查：

- 人物行为是否前后一致；
- 问题和回答是否匹配；
- 姓名、数字和称谓是否统一；
- 是否因局部修正造成新的矛盾；
- 是否存在无依据的新增、删除或改写。

如果局部结果破坏了全局一致性，就需要回退并重新判断。

## 五、五项核心原则

### 1. 原文锚定原则

原始 STT 文本是唯一事实起点。

推理可以改变错误的说话人归属、断句、标点和明显错词，但不能脱离原文创造新的事实、回答或情节。

### 2. 全文优先原则

局部不通顺不能只靠局部常识修复。

正确判断应优先参考全文中反复出现的事实、人物行为、对话主题和后续反馈。

### 3. 角色功能原则

说话人判断的核心不是原始标签，也不是句子长短，而是这句话在对话中承担的功能。

提问、回答、复述、解释、鼓励、评价、指令和转场，通常由不同角色稳定承担。角色功能比 STT 标签更可靠。

### 4. 最小干预原则

当多个重建结果都能解释原文时，应选择改动最少的结果。

后处理只修复影响理解和归属的错误，不把口语改写成更成熟、更规范的书面语。

### 5. 不确定性守恒原则

文本证据不足的地方，不能通过语言流畅度掩盖不确定性。

无法唯一恢复时，保留原始表达、使用省略或标记存疑，比强行给出确定答案更可靠。

## 六、对话结构重建方法

### 1. 语义轮次是基本单位

STT 原始段落、时间戳和发言人标签都可能错误，因此不能作为最终结构的直接依据。

最终划分应以"一个人在一次连续表达中完成的对话功能"为单位，例如：

- 提出一个问题；
- 回答一个问题；
- 复述并确认对方答案；
- 解释一项规则；
- 完成一次评价或转场。

一个原始段落可能包含多个语义轮次，一个语义轮次也可能跨越多个原始段落。

### 2. 问答关系提供结构约束

问题会限定下一句话可能表达的内容。

当长段中出现"问题 + 符合问题范围的短回答 + 对回答的复述或评价"时，应优先考虑其中包含多个说话人的轮次，而不是把整段归给同一个人。

### 3. 句子续接提供合并依据

如果相邻片段在语法、代词和语义上共同构成一个完整句子，即使原始标签不同，也应考虑它们属于同一说话人的连续发言。

尤其是极短片段，不能仅凭原始标签或长度判断为独立回答。

### 4. 复述不是机器重复

在访谈、教学、客服、咨询和会议场景中，一方经常复述另一方的关键词，用于确认、鼓励或继续追问。

因此，相同词语连续出现时，需要区分：

- 同一个人的识别抖动；
- 真实的强调或口吃；
- 另一个人的复述确认。

只有第一种情况可以在证据充分时去重。

## 七、说话人归属推理

说话人归属是多个文本证据共同作用的结果，不能由单一规则决定。

主要判断维度包括：

### 1. 对话功能

这句话是在提问、回答、解释、指令、评价还是转场。

持续承担相同功能的人，通常对应相对稳定的角色。

### 2. 相邻关系

提问后通常出现回答，回答后可能出现复述、确认或追问。

一句话在相邻对话中的位置，能够帮助判断它属于谁。

### 3. 语法连续性

检查前后片段是否共享主语、谓语、宾语、代词或未完成结构。

如果只有合并后句子才完整，说明原始切分可能错误。

### 4. 人称和指代

"我""你""他"的转换可以反映说话人切换。

一方回答时使用"我"，另一方复述时可能转换为"你"，这种变化是重要证据。

### 5. 角色行为稳定性

某个人是否持续提出新问题、说明任务、鼓励对方或决定活动流程。

角色行为在全文中的稳定程度，比单个发言人标签更有判断价值。

### 6. 后文反馈

后续内容可能证明前一句是问题、回答还是指令。

因此，说话人判断应允许使用后文反向验证，而不能只按从前到后的单句处理。

这些证据可以形成一个综合判断：

**说话人可信度 = 对话功能匹配 + 相邻关系匹配 + 语法连续性 + 人称一致性 + 全文角色一致性**

原始标签只是其中一个低可信参考项，而不是不可修改的事实。

## 八、文字恢复方法

### 1. 语义锚点恢复

姓名、机构名、地点、时间和专业词汇应先从全文中寻找稳定形式。

如果某个词在多处以相近形式出现，可以利用重复信息确定统一写法。

### 2. 上下文唯一性恢复

当某个异常词与当前主题明显不符时，不应立即删除，而应检查：

- 是否存在发音相近且符合当前主题的词；
- 是否与前后句共同构成固定表达；
- 是否是姓名、机构或领域词误识；
- 是否混入了另一人的短回答。

只有上下文形成唯一或高度稳定的解释时，才进行修正。

### 3. 最小字符修改

在能够恢复原意的前提下，优先选择字符改动最少、句序变化最小的方案。

大幅改写虽然可能更流畅，但更容易偏离真实发言。

### 4. 关键事实保护

涉及以下内容时应提高修改门槛：

- 否定与肯定；
- 人名和机构名；
- 数字、时间和年龄；
- 地点和身份；
- 因果关系；
- 情绪和态度。

这些信息一旦改错，会改变对话事实，而不只是改善语言表达。

## 九、重复与异常内容解释

重复和不通顺不能直接视为应删除内容。

### 重复内容的四种可能

1. STT 识别抖动；
2. 真实口吃或犹豫；
3. 说话人自我修正；
4. 另一位说话人的复述。

判断重复时，要看它是否承担新的对话功能，而不是只看字面是否相同。

### 异常内容的解释顺序

遇到明显不通顺的内容时，应依次考虑：

1. 是否被错误切断；
2. 是否混入另一位说话人的内容；
3. 是否存在上下文明确的同音误识；
4. 是否属于姓名、机构名或领域词；
5. 是否是重复识别造成的组合错误；
6. 是否确实无法仅凭文本恢复。

只有前五种解释都不能成立时，才将其保留为不确定内容。不能因为一句话"不合理"就将其判定为幻觉并删除。

## 十、置信度与修改决策

方法论采用三级判断：

### 高置信

全文事实、对话结构和局部语言证据指向同一结果。

可以直接调整说话人、断句或错词。

### 中置信

存在明显倾向，但仍有其他合理解释。

可以整理结构，但应减少字符修改，必要时保留原始表达或标记存疑。

### 低置信

文本无法确定真实内容或归属。

不进行实质性改写，保留原文的不确定性。

置信度不是模型主观"感觉"，而是不同文本证据之间的一致程度。

## 十一、最终文本形态

最终文本不应继续展示 STT 模型的碎片结构，而应展示重建后的语义轮次。

基本形态为：

- 一次发言一个段落；
- 一个段落只属于一个说话人；
- 发言人称谓全文统一；
- 问题、回答、复述和追问依次清晰；
- 最终阅读版默认不展示时间戳；
- 原始顺序和原始语义保持不变；
- 不在正文中混入推理过程和大段修改说明。

最终文件是一份"可阅读的对话转录"，而不是"带着模型错误痕迹的 STT 日志"。

## 十二、质量评价体系

后处理质量可以从五个维度评价：

### 1. 保真度

是否保持原意、顺序、态度和关键事实。

### 2. 完整度

原文中的信息是否都有合理去向，是否存在无依据删除。

### 3. 对话连贯度

提问、回答、复述、追问和转场是否形成自然关系。

### 4. 角色一致度

同一人物在全文中的语言功能和行为模式是否稳定。

### 5. 克制度

模型是否只修改证据充分的内容，是否保留了无法解决的不确定性。

高质量结果不是改动最多的结果，而是以最少改动消除最多结构性错误的结果。

## 十三、方法论总结

全局语境约束重建法的核心，是把 STT 原文视为真实对话的带噪文本投影。

它不依赖音频，也不假装获得了声学事实，而是利用对话自身的结构冗余进行恢复：

**全文事实约束局部词语，对话关系约束发言轮次，角色功能约束说话人归属，最小干预约束修改幅度，不确定性守恒约束推理边界。**

最终目标不是让文本更像一篇由 AI 写出的流畅文章，而是让它在现有文本证据范围内，更接近真实发生过的对话。
