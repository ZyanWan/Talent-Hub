# 电话软性表现证据框架

本框架只用于整理有转写事实支持的行为观察。没有充分依据时返回空数组，不生成中性占位判断。

## 可观察维度

| 维度 | 可观察证据 |
| --- | --- |
| 沟通表达 | 是否直接回应问题、主动澄清歧义、按问题调整详略 |
| 逻辑 | 是否先给结论，并用具体事实说明过程和结果 |
| 自驱 | 是否有主动行动、投入过程和实际结果 |
| 协作 | 是否说清自身、他人及跨团队的责任边界 |
| 诚信与一致性 | 时间、数字、职责和前后说法是否一致，矛盾是否有事实解释 |
| 责任心 | 是否说明责任边界、补救动作和结果承担 |
| 韧性 | 是否客观分析受挫原因并形成具体改进 |
| 学习能力 | 是否说明学习方法、验证过程和实际应用 |
| 开放性 | 是否能因事实或数据修正原判断 |
| 务实 | 是否给出可执行方案、具体细节和复盘 |
| 热爱 | 是否对具体工作内容有持续投入；薪酬和稳定诉求不属于负面证据 |

## 输出边界

- 每条观察同时包含有限判断和具体通话依据，并引用一个或多个有效 `fact_ids`。
- 普通应答、礼貌配合和正常介绍职责不构成积极信号。
- 单次含糊、口误或转写损失只能记录为单次表现，不能推断稳定人格倾向。
- 同一事实不得在多个维度重复计数。
- 不输出人格标签、置信度、推进建议或 A/B/C 结论。
- 不使用姓名、年龄、性别、民族、籍贯、婚姻或生育状况形成观察。
